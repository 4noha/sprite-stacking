# sprite-stacking（東雲はつり）

Kimo (@asynkimo) の sprite stacking の手順を、2.5頭身の東雲はつりで動かす。

1. **三面図を設計する** — `design.js`。正面 32×48 / 横 28×48 / 背面 32×48（GBA のスプライト程度）。パーツごとに3つの絵を持つ。
2. **絵をスライスにする** — `stack.js`。パーツの高さ1行ごとに、正面の横幅 × 横の奥行 に内接する丸い断面を作る。色は面の向きで決める（前=正面の絵、後ろ=背面の絵、横=横の絵）。
3. **1px ずつ積んで回す** — `index.html`。

## 使い方
`open index.html`（ビルド不要）。ドラッグの左右で向き、上下で見下ろし角（-90°〜90°。真横・真上・下からも見られる）。スライス間隔・描画倍率・輪郭線を切り替えられる。
描画は、積んだスライスの画素を1つずつ投影して手前を残す方式（`stack.js` の `renderVox`）。三面図と16方向シートをPNGで保存できる。
`index.html?auto=0&a=45&e=10` で向きと見下ろし角を固定して開ける。

## 既知の限界
- 等倍（×1）で斜めに回すと、細部の画素が崩れて読みにくい。既定は設計を等倍のまま ×3 で描く。
- 断面は1行につき1つの丸。くびれや穴は表現できない（パーツを分けて対処）。
- 陰影は絵に描いた分だけで、光源による陰影はない。
