# sprite-stacking（東雲はつり）

Kimo (@asynkimo) の sprite stacking の手順を、2.5頭身の東雲はつりで動かす。

1. **四面図を設計する** — `design.js`。正面 32×48 / 左横・右横 28×48 / 背面 32×48（GBA のスプライト程度）。パーツごとに正面・横・背面の絵を持ち、左右で違うパーツだけ左横の絵（`sideL`）を別に持つ。いまはキャップだけ（花のマークが左横の前の縁に回り込む）。
2. **絵をスライスにする** — `stack.js`。パーツの高さ1行ごとに、正面の横幅 × 横の奥行 に内接する丸い断面を作る。色は面の向きで決める（前=正面の絵、後ろ=背面の絵、横=その側の横の絵）。
3. **1px ずつ積んで回す** — `index.html`。
4. **動かす** — `motion.js`。積んだ立体をパーツごとに、高さ1行ずつ前後へずらして8コマの動きを作る（脚は腰、腕は肩が支点。ツインテとしっぽはなびく）。「歩く」は跳ねない。「走る」は歩幅が広く、足を開いた瞬間に体ごと跳ねる。歩幅・跳ねる高さ・腕の振りは `MOTIONS` の数値で変えられる。設計の絵は変えない。

## 使い方
`open index.html`（ビルド不要）。ドラッグの左右で向き、上下で見下ろし角（-90°〜90°。真横・真上・下からも見られる）。スライス間隔・描画倍率・輪郭線を切り替えられる。
描画は、積んだスライスの画素を1つずつ投影して手前を残す方式（`stack.js` の `renderVox`）。四面図と16方向シートをPNGで保存できる。
`index.html?auto=0&motion=none&a=45&e=10` で向きと見下ろし角を固定して開ける。
「動き」で 止まる / 歩く / 走る を選ぶ（既定は歩く）。動いているあいだは16方向シートが 16方向×8コマ（`hatsuri-walk-16x8.png` / `hatsuri-run-16x8.png`）になり、止まっていれば従来の1行。`?motion=none|walk|run` で動きを、`?f=0`〜`7` でコマを固定して開ける。

## 既知の限界
- 等倍（×1）で斜めに回すと、細部の画素が崩れて読みにくい。既定は設計を等倍のまま ×3 で描く。
- 断面は1行につき1つの丸。くびれや穴は表現できない（パーツを分けて対処）。
- 陰影は絵に描いた分だけで、光源による陰影はない。
- 歩き・走りは行単位のずらしだけで作っている。膝は曲がらない（肘から先を少し前へ出すだけ）。
