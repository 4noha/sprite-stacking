# sprite-stacking（東雲はつり）

Kimo (@asynkimo) の sprite stacking の手順を、2.5頭身の東雲はつりで動かす。

1. **三面図を設計する** — `design.js`。正面 32×48 / 横 24×48 / 背面 32×48（GBA のスプライト程度）。パーツごとに3つの絵を持つ。
2. **絵をスライスにする** — `stack.js`。パーツの高さ1行ごとに、正面の横幅 × 横の奥行 に内接する丸い断面を作る。色は面の向きで決める（前=正面の絵、後ろ=背面の絵、横=横の絵）。
3. **1px ずつ積んで回す** — `index.html`。

## 使い方
`open index.html`（ビルド不要）。ドラッグで回転。見下ろし角・スライス間隔・描画倍率・輪郭線を切り替えられる。三面図と16方向シートをPNGで保存できる。
`index.html?auto=0&a=45` で角度を固定して開ける。

## 設計
キャップ（前白・後ろ黒・つば裏ティール）に猫耳が貫通、薄紫の低めツインテ（膝まで）、ティールの瞳、首掛けヘッドホン、腿丈の紫パーカー（白リブ裾・白ラベンダー袖・紫カフス・猫顔パッチのポケット）、黒手袋、猫しっぽ（付け根に白リボン）、紫ハイカットスニーカー＋ライン入り白ソックス。
出所は Vault `03_Projects/hatsuri-image-gen` の確定設計。実物の画像は見ていない。

## 既知の限界
- 等倍（×1）で斜めに回すと、細部の画素が崩れて読みにくい。既定は設計を等倍のまま ×3 で描く。
- 断面は1行につき1つの丸。くびれや穴は表現できない（パーツを分けて対処）。
- 陰影は絵に描いた分だけで、光源による陰影はない。
