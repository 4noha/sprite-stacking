# sprite-stacking（東雲はつり）

Kimo (@asynkimo) の sprite stacking の手順を、東雲はつりで動かす。

1. キャラを **正面・横の2枚**のピクセル絵で描く（`index.html` 内の `front` / `side`）
2. 高さ1行ごとを **1枚のスライス**にする（両方の絵に画素がある所だけ残す = visual hull）
3. スライスを **1px ずつずらして積み**、まとめて回転する

## 使い方
`open index.html`（ビルド不要。ブラウザだけで動く）。ドラッグで回転、スライダーで角度・スライス間隔、ボタンで16方向のスプライトシートPNGを保存。

## 設計の出所
キャップ・薄紫ツインテ・ティールの瞳・首掛けヘッドホン・紫パーカー・猫しっぽ・紫スニーカー。Vault `03_Projects/hatsuri-image-gen` の確定設計に合わせた。
ツインテールと猫しっぽは2枚の絵に収まらないため、`extras` で3D直接配置。

## 既知の限界
- 16×10×38 の小ボクセル。ディテールは粗い。
- 回転した各スライスを低解像度キャンバスに描くので、角度によって縁がギザつく。
- 色は前半を正面、後半を横の絵から取る簡易方式。
